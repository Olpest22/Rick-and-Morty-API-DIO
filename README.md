# rick_morty_characters — приложение с API

Flutter-приложение, которое загружает список персонажей из открытого
[Rick and Morty API](https://rickandmortyapi.com/documentation) с помощью **Dio**,
парсит JSON в объекты Dart и показывает их на главном экране.

## Возможности

- Список персонажей с фото, статусом, видом и последним местоположением.
- **Бесконечная прокрутка:** следующие страницы подгружаются автоматически.
- **Поиск по имени** с задержкой 500 мс (запрос не уходит на каждую букву).
- **Фильтр по статусу:** все / жив / мёртв / неизвестно.
- **Обновление** жестом «потянуть вниз».
- Экран подробностей: вид, пол, происхождение, местоположение, количество эпизодов.
- **Обработка ошибок:** нет интернета, таймаут, ошибка сервера (5xx), неверный адрес (404),
  некорректный JSON. Пользователь видит понятное сообщение и кнопку «Повторить».
- Адаптивная сетка (1 колонка на телефоне, несколько на планшете), светлая и тёмная тема.

## Как устроен код

```
lib/
├── main.dart                               // точка входа, тема
├── data/
│   ├── api/api_client.dart                 // настройка Dio (baseUrl, таймауты, логи)
│   ├── api/api_exception.dart              // ошибки Dio → понятные сообщения
│   ├── models/character.dart               // модель персонажа + fromJson
│   ├── models/characters_page.dart         // страница ответа + пагинация
│   └── repositories/characters_repository.dart  // GET /character
├── controllers/characters_controller.dart  // состояние экрана (ChangeNotifier)
├── screens/                                // главный экран и подробности
└── widgets/                                // карточка, статус, картинка, сообщения
test/                                       // тесты парсинга и запросов (без сети)
```

- **Запрос:** `GET https://rickandmortyapi.com/api/character?page=&name=&status=`.
- **Парсинг:** ручные фабрики `fromJson`. Структура ответа простая, поэтому
  генерация кода не нужна. JSON декодирует сам Dio, а большие ответы он
  обрабатывает в фоновом изоляте.
- **Асинхронность:** устаревшие запросы отменяются через `CancelToken`, поэтому
  старый ответ не перезапишет новые данные. Повторная догрузка страницы
  блокируется, пока идёт текущая.

## Запуск

Требуется Flutter 3.10 или новее.

```bash
flutter create .   # создаст папки платформ (android, ios, web…), код не изменится
flutter pub get
flutter run
```

Для Android разрешение на интернет добавляется автоматически только в debug-сборке.
Для release-сборки добавьте в `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
```

Тесты (работают без интернета): `flutter test`
